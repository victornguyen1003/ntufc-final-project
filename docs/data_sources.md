# 資料來源實測紀錄

## Yahoo Finance（yfinance），W1 baseline 使用
- 範圍：20 檔大型股，2015-2024，每檔 2434 列。
- 休市日假資料：6 天（20 檔成交量全為 0、四價相同）。規則：整天刪除。
- 價格凍結：18 列個股成交量為 0 但市場有開（2317 於 2018-10-18~25 共 6 天、
  2603 於 2022-09-07~16 共 7 天，另 4 檔各 1 天）。Yahoo 複製舊價。規則：價格設 NaN。
- 2603 於 2022-09-19 的 -16.3% 為凍結後的累積報酬，不是除權息還原錯誤
  （Dividends 與 Stock Splits 皆為 0，未還原報酬同為 -16.3%）。
- 教訓：報酬門檻檢查會漏掉小幅的凍結價，成交量為 0 才是可靠指標。
